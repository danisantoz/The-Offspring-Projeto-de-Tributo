# The Offspring – Tribute Page 🎸

Projeto de tributo à banda **The Offspring**, desenvolvido durante um curso de **Frontend** realizado na plataforma **Udemy**.

## 📌 Sobre o projeto
Este projeto consiste em uma **página tributo**, criada com o objetivo de praticar os fundamentos do desenvolvimento frontend, como estruturação de conteúdo, estilização e organização visual.

A proposta foi construir uma página simples, clara e temática, homenageando a banda The Offspring.
